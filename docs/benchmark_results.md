# 방법별 외부 벤치마크 결과

이 문서는 정리 이전 `local_warps_dis_v1` 실험의 측정값을 보존한 기록이다. Python 3.10.12 / OpenCV 4.5.4 / NumPy 1.26.4, OpenCV·BLAS 단일 스레드에서 평가했다. 방법 코드는 [알고리즘 문서](algorithm.md), 지표와 집계 방식은 [벤치마크·평가 지표](benchmarks.md)를 따른다. 원시 PNG·로그·캐시·실행 스냅샷은 정리 요청에 따라 삭제하고 수치 표만 보존했다.

## 평가 규모와 해석

최종 평가는 580 HPatches 쌍 + 1,105 UDIS-D 쌍 × 33방법 = 55,605건이다. 각 영상 쌍의 기존 25방법 기하·개별 겹침 점수가 이전 실험과 동일함을 확인했다. DIS 8조합의 13,480건에서는 국소 보정 없는 대응 조합과 전역 H 및 처리 성공 상태가 같았다. DIS 적용 12,607건, 신뢰도 부족으로 생략 4건, 선행 전역 추정 실패로 미도달 869건이다.

국소 보정 없음/APAP/REW/DIS의 HPatches 평균 독립점 오차는 각각 0.5888/0.6731/0.6661/0.6519px이다. 국소 보정이 항상 기하 정확도를 높이지는 않는다. UDIS-D 평균 PSNR은 22.111/22.605/22.572/23.746dB, SSIM은 0.7170/0.7395/0.7393/0.7854이다. 이 광도 점수 향상을 정답 기하나 미관 개선과 동일하게 해석하지 않는다.

## 새 평가

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python3 -B stitching.py --task benchmark --workers 4
```

이 명령은 이 Markdown 문서를 새 실행 결과로 갱신한다. 시험 실행은 `--limit 1 --report /tmp/benchmark_pilot.md`처럼 별도 경로를 사용한다.

## 실행기 통합 후 검증

`experiments`·`scripts`를 `stitching.py`로 통합한 뒤 HPatches `i_ajuntament/1-2`와 UDIS-D `000002`에서 33방법을 대조했다. 총 66건의 처리 상태·전역 H·독립점 오차·PSNR·SSIM·공통 영역·개별 겹침 점수가 기존 실행기와 수치적으로 일치했다. 이 검증은 대표 두 쌍의 회귀 비교이며, 위 전체 벤치마크를 새로 전부 실행한 것으로 표시하지 않는다.
