# hdy: 이미지 정합 방법별 비교 결과

> **과거 실험 기록(2026-11-28 이전 구현):** 아래 수치와 당시 PNG는 현재 `stitching_hdy.py`의 실행 결과가 아닙니다. 현재 코드는 SIFT·RANSAC·공동 카메라 정렬로 교체되었으며, 새 코드의 RMSE·SSIM은 재측정하지 않았습니다. 과거 점수를 현재 코드의 성능으로 인용하지 마세요. 현재 결과는 [HDY 미션 결과](hdy_mission_results.md)를 참고하세요.

## 실험 의도와 범위

한 방법이 모든 사진과 투영에서 좋은지 확인하려고 같은 미션 입력을 여러 정합 방법으로 처리했습니다. Q1은 2장, Q2는 3장, Q3·E1·E2는 **같은 새 Q3 사진 8장**입니다. Q3는 원통 투영, E1·E2는 구면 투영을 사용합니다. E1은 블렌딩 없이 연결하고 E2는 같은 정합 결과에 멀티밴드 블렌딩을 적용합니다.

비교한 8개 주 방법은 Brown–Lowe, APAP, PixelStitch, UDIS2, DSFN, UniStitch, RopStitch, LPAM입니다. Brown–Lowe는 SIFT·RANSAC·전역 배치의 기준선이며, APAP는 위치별 국소 투영을 보정합니다. Q3·E1·E2에서는 나머지 모델의 사진 쌍 추론 결과를 8장 조립에 적용해 본 실험입니다. **이전 `stitching_hdy.py`는 Q1 Brown–Lowe, Q2 RootSIFT·MAGSAC(F06 변형), Q3·E1·E2 APAP식 Moving DLT를 선택해 구현했습니다.** 현재 공유 코드에는 이 조합을 사용하지 않습니다. 아래 숫자는 당시 실험 기록이며 현재 코드의 측정값이 아닙니다.

## 이전 구현에서 선택한 방법

| 미션 | 선택한 방법 | 같은 조건에서 확인한 근거 |
| --- | --- | --- |
| Q1 | Brown–Lowe | 8방법 비교의 검토된 시험점 RMSE·겹침 SSIM 모두 최고 |
| Q2 | RootSIFT·MAGSAC 변형 | Brown과의 별도 2방법 공통 영역에서 RMSE·SSIM 모두 개선 |
| Q3 | APAP식 Moving DLT | 연결된 8장, 제출 허용 후보의 공통 겹침 SSIM 개선 |
| E1·E2 | APAP식 Moving DLT | 같은 구면 정합을 사용하고 공통 겹침 SSIM 개선; E2만 블렌딩 |

이는 **당시 사진과 측정 조건에서 이전 구현의 후보를 고른 결과**이며, 모든 사진에 대한 최고 성능을 증명한 것은 아닙니다. 당시 단일 파일의 다섯 결과는 기존 해당 방법의 PNG와 픽셀 단위로 일치했지만, 현재 `stitching_hdy.py`에는 적용되지 않습니다.

## Q1·Q2: 검토된 시험점 RMSE와 공통 겹침 SSIM

| 방법 | Q1 RMSE ↓ px | Q1 SSIM ↑ | Q2 RMSE ↓ px | Q2 SSIM ↑ |
| --- | ---: | ---: | ---: | ---: |
| Brown–Lowe | **0.2287** | **0.9929** | 5.2920 | 0.5993 |
| PixelStitch | 0.2553 | 0.9346 | **1.4993** | 0.7340 |
| UDIS2 | 0.7713 | 0.9601 | 2.4971 | **0.7525** |
| DSFN | 9.1833 | 0.7204 | 17.7278 | 0.3617 |
| UniStitch | 1.9863 | 0.8577 | 5.4858 | 0.5604 |
| APAP | 0.2379 | 0.9925 | 5.1903 | 0.5885 |
| RopStitch | 3.4125 | 0.8197 | 8.5975 | 0.5039 |
| LPAM | 0.2301 | 0.9889 | 4.2774 | 0.6500 |

Q1은 검토된 시험 대응점 40개와 사진 쌍 1개, Q2는 각 쌍 40점씩 시험 대응점 80개와 사진 쌍 2개를 사용했습니다. Q2의 RMSE는 **각 쌍에서 먼저 계산한 RMSE의 단순평균**이며 SSIM도 두 쌍별 값의 단순평균입니다. 모든 방법에 같은 시험점과 해당 미션의 공통 유효 겹침 영역을 적용했습니다. Q1·Q2의 RMSE 좌표계가 서로 다르므로 두 미션 사이 RMSE 크기를 직접 비교하지 않습니다. 이 시험점은 기하 정답 전체가 아닌 검토된 표본입니다.

이전 구현의 Q2에 선택한 F06 변형은 위 8방법 표에 포함되지 않은 **별도 보충 비교**입니다. 아래 두 값은 같은 시험점 80개와 두 방법의 공통 겹침 영역에서 당시 단일 파일 후보로 확인했습니다. 평가 영역이 다르므로 위 표의 Q2 SSIM 0.5993과 아래 0.5960을 같은 측정값으로 취급하지 않습니다.

| Q2 방법 | Test RMSE ↓ px | 겹침 SSIM ↑ |
| --- | ---: | ---: |
| Brown–Lowe | 5.2920 | 0.5960 |
| RootSIFT·MAGSAC(F06 변형) | **4.8764** | **0.6079** |

RMSE 개선은 두 사진 쌍의 평균 결과입니다. 첫 쌍에서는 F06이 5.8197 px로 Brown–Lowe의 5.7531 px보다 조금 나빴고, 둘째 쌍에서는 F06이 3.9330 px로 Brown–Lowe의 4.8310 px보다 좋았습니다.

Q2 RMSE는 검토점을 제외하고 당시 새로 추정한 호모그래피의 오차이고, SSIM은 당시 최종 사진에 사용한 전체 매칭 호모그래피의 워프에서 구했습니다. 두 지표가 정확히 같은 변환 행렬을 평가한 것은 아닙니다. 이 지표로 F06을 선택했으므로 이 값은 **이전 구현의 방법 선택에 사용한 검증 결과**이며 새 입력에서의 독립 최종 성능을 증명하지 않습니다.

| Brown–Lowe | 연결됨, 접합 경계 보임 | 0.2954 |
| APAP | 연결됨, 접합 경계 보임 | 0.3269 |
| PixelStitch | 연결됨, 국소 변형·흐림 보임; Brown 배치 결합 | **0.6027** |
| UniStitch | 연결됨, 접합 경계 보임; Brown 배치 결합 | 0.2611 |
| RopStitch | 혼합 조립은 진단용; 접힘·경계 결함 | 비교 점수 없음 |
| LPAM | 이 입력의 8장 조립 실패 | 평가 불가 |
| UDIS2 | 세로 연결 실패 | 평가 불가 |
| DSFN | 큰 빈 영역·반복 장면으로 실패 | 평가 불가 |

입력 식별자는 `c013af857a8a`입니다. 점수는 Brown–Lowe, APAP, PixelStitch, UniStitch와 보충 실험 F06_component가 공유하는 **동일한 공통 겹침 영역**에 대한 평균입니다. F06_component의 같은 영역 점수는 0.2956이며 위 8방법 표의 주 순위에는 넣지 않았습니다. 비교 불가능한 방법의 자체 영역 진단 점수를 여기에 섞지 않았습니다. 새 Q3에 독립 검토된 미사용 대응점이 없어 Test RMSE는 모든 방법에서 평가하지 않았습니다.

## E1·E2: 같은 8장의 구면 파노라마

| 방법 | E1·E2 8장 결과 | 블렌딩 전 가로 6쌍 공통 겹침 SSIM ↑ |
| --- | --- | ---: |
| Brown–Lowe | 완료, 접합 경계 보임 | 0.3415 |
| APAP | 완료, Brown 초기 배치 사용 | 0.3744 |
| PixelStitch | 완료, Brown 전역 배치와 결합; 결함 보임 | **0.6250** |
| UniStitch | 완료, Brown 연결과 결합; 결함 보임 | 0.3147 |
| LPAM | 완료, 국소 흐름을 제한·평활화한 적응형 조립 | 0.5337 |
| RopStitch | 14쌍 중 8쌍 추론 성공, 8장 완성 실패로 기록 | 평가 불가 |
| UDIS2 | 세로 연결·유효 영역 부족으로 8장 실패 | 평가 불가 |
| DSFN | 세로 연결 실패, 빈 영역·반복 장면 | 평가 불가 |

사용자가 RopStitch–Brown 혼합 시안은 완성 결과로 채택하지 않고 **실패로만 기록**하기로 결정했습니다. LPAM의 성공 결과는 공식 모델만의 순수한 8장 조립이 아니라 **적응형 후처리를 포함**합니다. PixelStitch·UniStitch도 Brown 전역 배치에 의존하므로 각 모델의 단독 8장 성능으로 해석하지 않습니다.

E1·E2는 정합과 사진 쌍 워프가 같아 블렌딩 전 SSIM도 같습니다. 이 SSIM은 완성 사진의 자연스러움이나 E2의 블렌딩 품질을 측정하지 않습니다. 새 Q3처럼 검토된 별도 시험점이 없어 RMSE는 평가하지 않았습니다. 평가 설정은 512×384 프레임, 회색조 11×11 Gaussian 창(σ=1.5, K1=0.01, K2=0.03, L=255), 워프와 기준 사진 모두 유효하고 창 전체가 유효한 위치, 여섯 가로 쌍의 단순 평균입니다. 검은 픽셀값 자체를 무효로 취급하지 않았습니다.

E1·E2의 공통 평가 영역을 정한 다섯 방법은 Brown–Lowe, APAP, PixelStitch, UniStitch, 적응형 LPAM입니다. Q3 원통 실험과 참여 방법 및 투영이 다르므로 Q3의 0.6027과 E1·E2의 0.6250을 직접 비교하지 않습니다.

## 결론과 해석 주의

- Q1은 Brown–Lowe가 8방법 비교의 두 지표 모두 가장 좋았습니다. Q2의 8방법 비교에서는 PixelStitch가 RMSE, UDIS2가 SSIM에서 앞섰고, 이전 OpenCV·NumPy 단일 파일 후보 중에는 별도 검증한 F06 변형을 선택했습니다.
- 새 Q3와 구면 E1·E2에서는 PixelStitch의 **겹침 SSIM**이 가장 높았지만, Brown 배치와 결합한 결과이며 완성 사진의 눈에 띄는 결함이 남았습니다.
- 따라서 이 데이터만으로 모든 미션에 대한 단일 최고 방법을 확정하지 않았습니다. 완성 사진의 연결·접합선, 실패 여부, 입력별 공통 겹침 지표를 함께 보아야 합니다.
- SSIM은 노출·밝기 차이의 영향을 받습니다. 서로 다른 미션의 SSIM은 투영·평가 영역·참여 방법이 달라 직접 순위 비교에 쓰지 않습니다. Q1·Q2의 RMSE는 검토된 표본에 대한 값입니다.

F06 변형은 위 8방법의 주 비교 표에는 없지만, 별도 같은 조건 검증 후 이전 구현의 Q2에 채택했습니다. 이전 구현의 Q3·E1·E2에 선택한 APAP는 Brown 전역 배치를 초기값으로 사용하는 국소 보정 포트이며 APAP 논문 전체 시스템을 재현한 것은 아닙니다. 외부 HPatches/UDIS-D 벤치마크를 현재 hdy 코드로 실행했다고 주장하지 않습니다. 현재 사진 5장의 출처와 실행법은 [hdy_mission_results.md](hdy_mission_results.md)를 참고하세요.
