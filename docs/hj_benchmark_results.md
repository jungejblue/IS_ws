# hj 모델: HPatches · UDIS-D 벤치마크

비교: baseline(Q1-1) 과 문제별 최종 모델 Q1-5 · Q2-4 · Q3-7 · E2-5 (E2 는 블렌딩만 달라 정합 = E1 ⑦).
데이터: HPatches 580쌍 (각 시퀀스 1 ↔ 2~6), UDIS-D 시험 1,105쌍 (`data/benchmarks/`). 지표·실패 처리는 `docs/benchmarks.md` 와 같음.
각 모델을 두 영상에 그대로 적용 (baseline 은 Q1 경로, 여러 장 모델은 원통·구면·BA 를 거쳐 원래 좌표로 되돌림). 오차는 성공 쌍, 성공률·AUC 는 실패를 0점으로 넣은 전체 쌍 기준. AUC 는 국소 보정까지 포함한 최종 변환으로 계산 (팀원 표는 보정 전 전역 H).
UDIS-D 는 이 다섯 모델의 공통 겹침 영역 (75.84%) 이라 팀원 33방법 공통 영역 (74.91%) 과 다름.

측정 기록: 통합 전 실험 코드로 전체를 측정한 값이고, `stitching_hj.py --task benchmark` 로 일부 쌍(HPatches 7쌍 · UDIS-D 6쌍, 방법 8개)을 다시 측정해 쌍별 값이 같음을 확인함. 환경: Python 3.13, OpenCV 5.0.0.
재측정: `python stitching_hj.py --task benchmark --case Q1-1 Q1-5 Q2-4 Q3-7 E2-5`

## 해석

- UDIS-D (시차 있는 실제 장면): Q3·E2 모델이 가장 좋음 (baseline 보다 PSNR 1.8dB 높고 88% 쌍에서 더 높음).
- HPatches 시점 변화 (평평한 그림을 다른 위치에서 촬영): Q1 모델이 가장 좋음. Q2·Q3·E2 모델은 카메라 회전을 가정하고 원통·구면에 먼저 펼쳐 크게 떨어짐 (예: v_tempera 1↔6 에서 Q1 모델 1.18px, Q3 모델 23.5px).
- HPatches 조명 변화와 sub-pixel 정확도: baseline 이 가장 좋음 (정답이 homography 하나로 정확히 맞는 데이터).
- Q3·E2 모델의 RMSE 가 큰 것은 크게 틀린 시점 변화 쌍 몇 개 때문 (쌍별 RMSE 의 평균).
