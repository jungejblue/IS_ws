# hj 모델: Q1~E2 미션 측정 결과

`stitching_hj.py --task evaluate --case all` 로 측정. 입력: `data/Q1`(2장), `data/Q2`(3장), `data/Q3`(8장), 합성용 긴 변 1400px (baseline 도 같은 크기로 입력).
환경: Python 3.13, OpenCV 5.0.0, NumPy 2.5 (팀원 측정 환경 OpenCV 4.5.4 와 다름). 방법 번호는 `--task list`, 1 = baseline (B0 와 같은 코드).

- 어긋남: 사진이 바뀌는 경계 20px 띠에서 무늬 있는 픽셀의 DIS flow 크기. `>2px` 는 2px 넘는 비율
- 밝기 차이: 같은 띠의 평평한 곳에서 흐린 밝기 차이
- 정합 오차: 정합에 쓰지 않은 ORB 대응점을 각 사진의 변환으로 합성 좌표에 올렸을 때 거리 (baseline Q2~E2 는 원통·구면 재투영 전 합성 면)
- Q1~E1 은 블렌딩 없이 덮어쓰기, E2 만 블렌딩. 정답 기하가 없어 PSNR·정답 오차는 재지 않음
